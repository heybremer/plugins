# Bloggie Test Notes

This plugin includes two runtime test routes:

- `plugins/Bloggie/api/test.php?token=...`
  - checks DB, API key presence, product SEO data query, OpenAI connectivity
- `plugins/Bloggie/api/generate.php?token=...`
  - runs one full generation and stores a blog post

Use the Dashboard "Test Merkezi" buttons for easier execution.
